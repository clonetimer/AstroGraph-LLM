# LAB_EPS_V1 电源试验记录（合成测试资料）
 ## 电池内阻增大假设
 电池内阻增大可能造成负载下端电压下降；必须排除瞬态大负载、温度影响和电压采样误差。

 ## 排查约束
 检查同时间窗口的电流、电压、SOC、温度和 BMS 告警。不允许系统自动修改充放电参数。
