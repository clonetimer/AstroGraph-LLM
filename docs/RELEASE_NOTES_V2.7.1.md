# AstroGraph Portable V2.7.1 Preview — 首次试用界面微调

版本：2.7.1-preview.1。日期：2026-11-04。基线：V2.7 完整便携包。

## 本轮改动

1. 开始分析、测试连接使用底部粘性操作栏；按钮保持可见，发送位置/连接测试说明保留。模型设置顶部的运行方式和连接预设并排，1366×768 下主要连接字段可在首屏看到。
2. 当前模型条移到诊断材料上方，包括未配置、已填写但未测试、列表接口连通及测试失败状态。修改连接信息会清除旧测试状态；连通状态不证明生成能力。
3. 编码/容量说明默认折叠；每份材料的角色仍然直接可选，文本编码可展开修改并在折叠标题显示已选编码。主要输入、操作按钮和报告正文调整到 14 CSS 像素，辅助说明适度增大。
4. 多报告综合结论与建议核查前置；单报告先摘要再核查。不重新计算或改写原报告、不删除证据、假设、分歧和缺失信息，不改变导出结构。

## 沿用

六项导航、材料导入、模型调用、长文/多报告分析、原文引用、问答、历史备份恢复、中断继续保持原功能。Windows x64 Python、packages、分析核心与 CHECK.bat/START.bat 继承 V2.7，保留路径引号修复。没有引入 CDN、前端构建依赖或模型权重。

## 试用与更新

请完整解压到新目录，先 CHECK.bat，后 START.bat。在模型设置中填写本机服务或在线 API，测试后选择实际模型 ID，再用短诊断文本完成首次分析。连通测试仅读取模型列表；真正生成一份报告才验证生成接口。

旧任务先备份后恢复；同编号任务不覆盖。不要只替换旧版界面文件。日常使用无需源码构建或安装 Python/Node；完全断网生成仍需要已准备好的本机模型服务和权重。

## 验证边界

Linux Python 与真实 Chromium 组件测试；界面 API 使用脚本化返回，后端回归使用本机模拟 HTTP 模型。不是 Win10 原生实机或真实模型质量验收。本轮未写入 GitHub。pypdf 仍为继承版本 5.9.0；只使用可信 PDF，扫描件需先 OCR。以随包 VERIFICATION_V2.7.1.md 记录的实际结果为准。
