# LLM 主动诊断：开发版研究计划

文档状态：`CURRENT_DEVELOPMENT_EXPLORATORY`。

状态：探索性实现。稳定版 `AstroGraph`、正式证据、冻结确认性实验和生产资格不在本计划的修改范围内。

## 研究问题

在相同遥测和明确预算下，让 LLM 选择尚未进入当前判断的观测，是否能在控制健康误警的同时提高故障识别并减少拒判？研究对象是“调查策略增益”，不是让模型绕过证据校验或独立裁决。

## 已实现边界

- LLM 可提出竞争候选、选择白名单探针、读取新观测并给出影子候选修订或弃权建议。
- 主机只接受已登记候选和本轨迹内的观测 ID；无效输出失败关闭。
- 只有实际暴露主动观测、修订引用该观测且候选集发生变化时，才记为影子候选细化。
- 新观测不自动成为 `EvidenceFact`，不改变正式 `HypothesisSet`、确定性诊断、KG 或裁决结果。
- 评价真值在推理结束后才连接；外部验证组不用于开发选择。
- 数据入口允许隔离未映射但无害的字段；标签、故障注入和事后真值仍硬隔离。含糊的 `mode` 字段必须先取得字段角色和来源证据。

## 当前证据

1. A2/A8 真实 OPS-SAT 成对运行中，A8 没有选择新观测，主动效果不可识别。
2. 六个真值无关原始段探针的组合只有很弱信息量；确定性嵌套校准 A11 在 227 条开发轨迹上取得 `balanced_accuracy=0.616831`、`recall=0.244898`，健康误警 `2/178`。
3. A12 的简单通道条件化只多召回 1 条异常，却新增 18 条健康误警，已拒绝。
4. A13 读取官方派生特征，并排除时长/长度代理。相同嵌套协议下取得 `balanced_accuracy=0.783650`、`recall=0.612245`、`F1=0.689655`，健康误警 `8/178`。这说明当前首要瓶颈是观测表示，而不是扩大 Agent 权限。
5. A14 将同一组长度无关特征和严格 OOF 校准摘要交给 LLM。8 个配对病例全部保留双候选或弃权，6 个引用主动观测，0 个形成可归因候选细化；相同病例 A13 正确 5 个。当前证据不支持让通用 LLM 直接替代确定性状态判别。
6. A15 在相同 8 个开发病例和一次新观测预算下比较四种动作策略。Qwen3.8-27B 的 16 次调用均选择训练集信息增益最高的 `inspect_early_late_shift`，因此与确定性信息增益策略结果相同：准确率（弃权计错）`0.375`、健康误警 `1/4`；稳定随机合法动作是 `0.5`、健康误警 `0/4`。LLM 确实暴露并引用了新观测，但尚无策略增益，下一步应先扩充有区分力的动作与表示，而不是提高权限。

## 优化实现状态

- 新增同病例、同一次新观测预算的四臂动作策略比较：无新观测、仅用 `MODEL_TRAIN` 拟合的信息增益策略、稳定随机合法动作、LLM 动作策略。健康病例统一带有“工单怀疑异常”的错误前提，真值仍在全部在线臂返回后连接。
- LLM 只选择登记动作或停止；测量值、动作阈值和状态映射由确定性工具完成。报告同时记录主动观测暴露、可归因变化、健康误警、弃权、耗时、token 和内容绑定请求 ID。
- 新增分组 split-conformal 候选集回执。校准按独立组的最大非一致性分数完成；空集或多候选均建议弃权，空集仅作完整标签集的运行时安全回退，不产生正式证据。
- 新增机器可读 pytest 执行画像与分类跳过预算。画像通过只表示已收集测试未突破其遗漏预算，不等于历史资产、外部数据、模型或生产资格通过。
- SVC 概率输出改为显式交叉验证校准，并复用诊断基线样本 fixture，减少全量回归的重复训练成本。

## 下一阶段

### P1：把 LLM 用于调查决策，而不是数值分类（已实现，效果待外部验证）

为每个候选定义可执行的“下一观测—预期区分”合同。LLM 只选择下一项检查或停止；数值测量和校准由确定性工具完成。验收要求是同预算下获得额外、可核验信息，并改善候选集或合理增加弃权。

### P2：改进观测表示（开发证据支持，继续作为 challenger）

优先研究在线可计算、与段长度无关的局部动态特征、残差、命令—响应关系和反事实差异。所有候选先在开发集做嵌套评估，并同时约束健康误警、召回和拒判；不能只按总体准确率晋升。

### P3：校准弃权并冻结确认性比较（校准组件已实现）

方法冻结后，再固定数据快照、可见信息、分组、阈值、预算、评价单位和包括拒判在内的分母，使用未参与选择的独立组。缺少可靠连续时长时，不报告单位时间误警。

分组保序校准当前只用于影子候选集合与弃权建议。它要求校准组和评估组显式互斥，并把有限样本 `+∞` 修正映射到有界 `1-p` 分数；交换性被破坏、时间漂移或选择性标签存在时不声称覆盖保证。

### P4：运行与复现身份（已实现基础回执）

OpenAI 兼容调用发送内容绑定 `X-Request-Id`，并把全部尝试的请求 ID 写入调用历史。动作比较报告记录 `/models`、`/version` 响应、模型名、输入文件哈希和服务端 token 用量；SSH 转发方式与远端启动参数仍需在包外运行回执中冻结，不能仅凭接口自报完成服务资格。

### P4：知识晋升

文献和经验可以提出 KG 候选，但重复检索不增加证据强度。只有完成来源去重、独立病例结局、反例和留出集消融，并经审核发布的可执行关系，才可能由当前遥测触发并进入融合。

## 停止规则

- 没有新观测暴露：结论为主动效果不可识别。
- 有观测但没有引用及候选变化：不得称为候选细化。
- 仅在开发集或小样本改善：不得称为确认性增益。
- 确定性工具优于 LLM 元决策：保留 LLM 的调查规划角色，不扩大其正式裁决权限。
