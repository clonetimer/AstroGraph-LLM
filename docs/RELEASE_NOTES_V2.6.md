# AstroGraph Portable V2.6 交付修正版（Preview）

版本：2.6.0-preview.1；日期：2026-11-03。范围冻结为外部诊断材料 → LLM 分析 → 报告、引用、追问和本地历史。

## 本次实际修复

1. 修复界面虽然列出 PDF/DOCX、实际文件校验却拒绝这两种格式的问题；PDF/DOCX 也可选择参考资料角色。
2. 长报告综合分析不再将每个片段摘要硬截到 4,000 字符。完整摘要进入综合阶段；总摘要超过 120,000 字符时明确停止，并保留检查点。LLM 摘要本身仍可能概括或遗漏信息，不等于无损处理。
3. 将共识、分歧、互补证据、时间对齐中的引用映射回原始来源；去掉前端重复显示的对照卡片。
4. 模型失败后可在原任务点击“继续 / 重试分析”。输入哈希和原模型身份重新校验；已完成的长报告片段复用，短报告会重新调用模型。成功恢复后不再显示重试状态。
5. 运行模型时禁止备份和恢复，避免保存一半的任务；恢复时拒绝 Windows 大小写同名、保留名、末尾点等路径别名，恢复的 RUNNING 任务立即转为 INTERRUPTED。
6. PDF/DOCX 在独立解析进程运行，最长 30 秒；扫描/无文本 PDF 给出 OCR 提示，加密 PDF 给出解锁提示。Linux 解析测试另外有内存上限，**未声称 Windows 已有同等内存限制**。
7. CHECK.bat 先校验包清单，再离线自检，并将结果写入根目录 CHECK.log；自检日志不包含用户报告或 API Key。
8. 源码与测试以完整的便携源码目录提供，并附针对已核验 GitHub 基线的补丁；不再依赖多份相互叠加的旧补丁。

## 保留的使用方式

完整解压到新目录，运行 CHECK.bat，再运行 START.bat。界面无需安装 Python、Node 或 pip；模型服务和权重不在包中。在线模式会发送所选材料到配置的服务，本地模式只连接本机回环地址。旧任务通过 V2.5 备份后恢复到新目录，或停机后复制 data 文件夹；同编号任务不覆盖。

## 验证边界

已执行 Linux 隔离环境的应用/API 回归、离线自检、Python 编译、JS 语法及真实 Chromium DOM/JS 组件测试。浏览器组件测试使用固定 API 响应；另外的后端测试使用真实本机 HTTP 模型桩。二者均不能替代真实在线/本地模型或 Windows 10 实机验收。详细命令与结果在 VERIFICATION_V2.6.md。

## 仍未关闭的事项

- 不能标记 Stable：目标 Windows 10 与生产模型尚未实测。

- 不做 OCR，不保证复杂 PDF 多栏/表格语义或 DOCX 浮动图形完整；先核对提取的原文。
