# AstroGraph Portable V2.7.1 Win7 x64／Python3.8 试用包

版本：2.7.1-win7-py38-preview.1；日期：2026-11-04。

## 保留

V2.7.1六页导航与布局微调，诊断材料导入、PDF/DOCX、长文本分块、多报告对照、引用、追问、历史备份恢复、中断续跑和导出。没有引入诊断计算或训练。现有Win10包不修改。

## 适配

- 内嵌官方Python3.8.10 x64；依赖更换为兼容的Pydantic2.10.6/core2.27.2 CP38及类型注解兼容组件，未删除严格校验。
- Annotated、resources、路径包含检查、哈希和运行时注解适配3.8。
- HTTPS添加随包CA证书，保持证书校验、TLS>=1.2、禁止静默重定向及本地代理隔离。
- 新增离线系统条件检查，启动继续保留已修复的目录引号处理。
- 独立固定哈希离线构建，包含可阅读运行源码、单元/集成测试与中文版使用说明。

## 交付条件

Win7 SP1 x64、必需系统更新/UCRT、已安装的现代兼容浏览器。模型服务/权重、浏览器、系统补丁不包含。先 CHECK.bat 再 START.bat，优先用短文本和在线API试用。本地模型软件必须独立验证Win7支持；本轮没有新增任意局域网HTTP模式。
