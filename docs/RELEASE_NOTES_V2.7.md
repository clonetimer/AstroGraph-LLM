# AstroGraph Portable V2.7 Preview — 导航与交互统一版

版本：2.7.0-preview.1。日期：2026-11-04。

## 本版交付

以已交付 V2.6.2 的源码和 Windows 二进制为基线，改为深色固定侧栏 + 浅色工作区。六个实际入口：开始分析、分析结果、历史任务、证据问答、模型设置、使用帮助。没有添加无法使用的知识图谱、审核或 Agent 按钮。

- 开始分析：保留粘贴文本、文件上传、材料角色、编码与分析目标；增加当前模型摘要与设置跳转。
- 分析结果：保留长文/多报告分析、完整原文引用、MD/JSON 导出、失败重试和中断续跑。
- 历史任务：独立任务列表、关键词/状态筛选、打开任务、备份与恢复；所有条目来自本机任务存储。
- 证据问答：独立页面，仍绑定所选任务；回答中的引用可以跳回分析结果并展开原文。
- 模型设置：原有在线 API/本机模型设置，切换页面不清除连接内容。API Key 仍不持久化。
- 使用帮助：内置离线上手步骤、输入限制、常见故障和迁移说明。

## 状态保持与无障碍

页面使用持久 DOM 面板，不在导航时重建表单。切换导航保留材料、粘贴内容、未发送问题、当前报告和模型设置。切换到另一任务时，问答上下文随任务切换，不混用之前任务的问题或回答。分析期间可浏览其他页面；进度轮询不会把用户强制跳回结果页，也不会重新提交模型调用。

支持浏览器前进/后退、键盘导航与可见焦点、窄窗口抽屉导航、Escape 收起。分别验证 390、900、1024、1280、1440 CSS 像素宽度。

## 便携性与兼容范围

Windows x64 运行时、packages 固定依赖及 src/astrograph 分析核心未修改。保留 V2.6.2 CHECK.bat 路径引号修复。目标机完整解压后无需另装 Python、Node 或联网安装依赖；本机大模型服务与权重仍需单独准备。

仅便携工作台更新；没有提交 GitHub，也没有把完整仓库切换为同一前端。navigation.js 是可复用的视图导航模块，不等于完整项目已完成前端共享改造。本源码包是最小便携模块集合，不可整体覆盖完整仓库。

## 更新方式

1. 将完整 V2.7 ZIP 解压到新目录，避免覆盖旧版。
2. 双击 CHECK.bat；完整性与离线自检成功后运行 START.bat。
3. 在“模型设置”连接模型，然后进入“开始分析”。
4. 旧任务可在旧版备份，再到 V2.7“历史任务”恢复；或关闭两边程序后复制 data 目录。同编号恢复不覆盖。

不要只把新的 HTML/JS 拷贝进旧包；旧清单会正确报告哈希变化。请使用完整包。

## 已知验证边界

仍为 Preview。实际执行在 Linux/Python 与 Chromium；模型端为脚本化本机 HTTP 服务或界面测试数据，不代表真实模型质量。直接 Chromium 导航到本机服务被执行环境策略 ERR_BLOCKED_BY_ADMINISTRATOR 阻止，未计为通过；实际 DOM/JS 组件测试及独立真实 HTTP 测试分别执行。原生 Windows 10、随包 python.exe 与 bat 的现场运行未在本环境验证。

pypdf 仍继承 5.9.0，本轮未升级。仅导入可信 PDF，扫描件需先 OCR；复杂版式应核对提取文本。导航改造不改变已有容量、引用校验与模型不确定性边界。
