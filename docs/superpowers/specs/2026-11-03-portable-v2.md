# AstroGraph Portable V2 — Approved Scope

The user approved evolving the Windows 10 x64 portable workbench into a light deployment shape of AstroGraph-LLM, sharing the same external-diagnosis analysis contracts.

## User-facing goal
Import one or more externally generated diagnosis reports, use an online OpenAI-compatible API or a preinstalled local model server, and display a cited analysis. No diagnostic calculation is performed by this product.

## V2 scope
1. Restore direct PDF and DOCX import.
2. Add long-report processing using bounded chunking, hierarchical synthesis, preserved provenance and explicit resource limits.
3. Add multi-report comparison: consensus, contradictions, complementary evidence, event/time alignment and integrated conclusions.
4. Improve visual report comparison and citation navigation.
5. Preserve local history, backup/export and restart recovery.
6. Ship a self-contained Win10 x64 package; target machine needs no Python/Node/pip/network installation. Model service and weights are external prerequisites for local inference.

## Non-goals
Telemetry diagnosis, fault detection, training, simulation, automatic model downloads, mandatory graph database, or server deployment.

## Safety and evidence rules
Original files are immutable. Extracted text is separate and hash-bound. Page/section/row locators must survive parsing and chunking. Scanned PDF is OCR-required; never fabricate text. Every synthesized finding must point to original source IDs. Contradictions remain explicit; different event windows must not be conflated. Online mode warns that files/questions are sent to the configured provider; local mode is loopback-only.

## Deployment
Keep offline Python runtime and all dependencies bundled. No CDN. Credentials remain memory-only. Windows native verification status must be reported truthfully.
