# AstroGraph Portable V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Upgrade the Windows 10 x64 portable workbench with native PDF/DOCX import, source-preserving long-report analysis, cross-report comparison, and a usable comparison UI while retaining offline installation and online/local model modes.

**Architecture:** Extend the portable application in layers. First reuse the existing structured DOCX parser and add a bounded PDF extractor with page locators. Then add deterministic source-aware chunking and hierarchical LLM synthesis that reuses the canonical report schema. Finally add report comparison artifacts/UI, durable history, and rebuild the self-contained Windows ZIP.

**Tech Stack:** Python 3.14 embedded x64, existing Pydantic/core modules, stdlib ZIP/XML parsing for DOCX, pypdf for PDF, existing OpenAI-compatible backend, plain HTML/CSS/JS.

**Spec:** `V2_SPEC.md`.

## Global Constraints
- Windows 10 x64; local web server binds only to 127.0.0.1.
- No online installation or admin rights on target; API online or preinstalled loopback model server.
- No diagnostic computation, telemetry processing, model training, or mandatory graph database.
- Preserve original uploaded bytes, SHA-256, page/section/line locators and task source binding.
- Never silently truncate or omit evidence; every chunk and synthesis claim retains provenance.
- API credentials remain memory-only; reports, conversations and source files stay local.
- Scanned/image-only PDFs are explicitly OCR-required; no fabricated text.
- Native Windows execution is not claimed without Windows 10 evidence.

## Review Focus
- Malformed, encrypted, oversized and maliciously nested PDF/DOCX inputs.
- Tables, headings, multi-column pages, mixed Chinese/English text and missing glyph extraction.
- Long reports whose chunk boundaries split conclusions, table rows, or citations.
- Contradictory reports, duplicates, same component but different event windows.
- Interrupted multi-stage analysis, retry idempotency, and stale UI responses.
