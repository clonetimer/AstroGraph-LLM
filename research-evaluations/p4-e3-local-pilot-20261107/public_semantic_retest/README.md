本次四个输出都低于 850 token 上限，原生 API 未给出独立 `finish_reason`。因此不能用预算截断解释这些具体错误。`source_fact_anchors.json` 保存了输入中的逐项依据及本轮初审的解释边界，**仅是开发侧评审锚点，不是独立金标准或专家签署**；人工判断保留了原始响应，未改写输出。

结论：不把这套“先写来源量表”的自由文本提示直接接入平台。对任意资料做事实抽取时，下一阶段应让每条时间、数量、设备构型关系绑定原文片段与来源位置，并在报告生成前检查原文确有该片段；对数量归属、因果解释仍需独立语义复核。不能因为 9B 在一个案例列对数字，就认定它能在另一案例正确使用时间与因果关系。
