## P4-E2 评审口径（预登记草案）

对同一冻结输入分别盲评每份报告；先看事实错误，再看表达。每项记 `0=错误/缺失`、`1=部分可用`、`2=明确可用`，并附原文位置、输入来源位置和判断理由：

1. **故障现象**：时间、工况、数值、单位与输入一致；未把命令量写成反馈量。
2. **候选原因**：区分观测、分类结果和机理假设；说明支持、反证与未知，不倒置因果。
3. **引用依据**：每个关键断言可定位到相应输入或文献段落；文献常识不冒充本次测量。
4. **核查建议**：指出所需数据、同步时间窗/工况及能支持或削弱候选的判据。
5. **处置边界**：建议具体且符合权限；不把分析建议写成已授权设备操作。
6. **可读性**：维护人员能从首屏读出结论、依据与下一步；无字段碎片、占位符、重复段落。

关键错误单独标注：错误单位或数量级、虚构观测、错引来源、将未知证据当支持/反证、未经授权的控制建议。总分不能抵消关键错误。评审记录须绑定模型输出和输入哈希；评审者身份、时间、意见分歧及裁决均保留。当前**尚无独立领域专家评审或质量通过率**。
