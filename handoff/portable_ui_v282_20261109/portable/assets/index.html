    GETTING STARTED

    使用帮助

    从启动工作台到查看第一份报告，以及常见问题的处理方式。

    上手流程

    1. 完整解压到可写目录，先运行 CHECK.bat。
    2. 双击 START.bat，用已有的 Edge 或 Chrome 打开本机界面。
    3. 进入“模型设置”，配置在线 API 或已启动的本机模型。
    4. 在“开始分析”导入诊断报告，设置材料角色和分析目标。
    5. 在“分析报告”查看报告、点击引用，在“报告问答”继续追问。

    保留启动控制台。关闭网页不会停止服务；退出请在控制台按 Ctrl+C。

    常见问题

    没有 Python，也能启动吗？

    包内已有 Windows x64 解释器和依赖，无需另装 Python 或 Node。需要完整解压，不能只复制启动脚本。

    可以完全断网吗？

    工作台可以离线启动。生成分析需要在线 API，或已经准备好的本机模型服务和模型权重；便携包不含模型。

    为什么报告里没有模型结论？

    “报告已保存”和“模型分析成功”是不同状态。查看结果页原因代码，核对模型 ID、超时和输出格式，再点击“继续 / 重试分析”。

    PDF、长报告有哪些限制？

    总文件上限 4 MiB，解析后文本上限 180,000 字。扫描 PDF 需先 OCR；仅导入可信 PDF，复杂版式需核对提取文本。长文分块分析可能多次调用模型。

    如何迁移历史或恢复中断任务？

    在“历史任务”备份并在新目录恢复，已有同编号任务不会覆盖。模型操作进行时不能备份；中断后在结果页点击“继续 / 重试分析”，使用原模型身份。

    CHECK 报错应检查哪里？

    查看根目录 CHECK.log。V2.8.2 保留 V2.6.2 路径引号修复，不要混用旧 CHECK.bat。若文件校验失败，请重新完整解压，而不是删除 MANIFEST.json。
