# 第四环节功能清单

以下状态只描述本源码包的实现与 2026-11-07 的核验范围，便于合并时逐项确认。

| 功能 | 当前状态 | 合并时必须保留或核验的行为 |
|---|---|---|
| 新建分析与材料上传 | 本机账户浏览器流程通过 | 诊断结果、运行日志、参考资料上传与预检；任务编号贯穿报告和任务总览 |
| 多模型与规则引擎选择 | 代码路径存在；本机 9B 与规则流程已试 | 配置由管理员管理；用户在新建分析选择引擎；未配置模型时可走规则路径 |
| 结构化模型解释 | 本机合成 TC01 调用通过 | 模型说明必须区别候选与确诊；引用 ID 属于当前可见来源；日志数值与所引摘录一致 |
| 来源纠错 | 合成 9B 案例一次反馈后通过 | 只有一次主机校验反馈重试；重试仍不合格则拒收模型解释，保留冻结诊断 |
| 本次上传文献检索 | 本机流程与后端测试覆盖 | 上传文献是待审参考，不自动成为任务遥测或已审图谱事实 |
| 已审知识图谱与历史案例 | 后端合成契约、前端弹窗合成来源测试覆盖 | 区分图谱关联、历史已审资料、历史案例、上游误判反例；不自动确诊当前根因 |
| PaperSeek 与 Anything2Ontology | 按配置可启用；本轮未完成目标部署验证 | 外部检索与候选建图分别标注来源，待审候选不能自动写入已审知识 |
| 报告与来源定位 | 原生 Chrome 真页面测试通过 | 首屏结论、依据、核查建议；点击引用可见文件、行号、角色、摘录与边界说明 |
| 账户与专家复核 | 本机管理员建号、专家登录和提交复核通过 | 复核留痕；模型建议不代表已授权设备操作 |
| 首页任务显示 | 本机 1440×900 截图通过 | 真实任务号和状态来自任务概览；地球轨道为演示图，不冒充实时遥测 |

**仍未证明：**真实卫星遥测与上游 BiRRF 整链的目标部署验收、来源语义真实性、故障诊断准确率、独立金标准、双专家一致性和模型优选结论。不要把结构化 JSON、引用编号或浏览器页面通过写成上述质量结论。
