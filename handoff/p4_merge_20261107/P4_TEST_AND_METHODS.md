## 改动依据与取舍

- **结构化输出 + 主机校验**：用于约束字段、冻结候选、核对来源 ID 与数值；它能拒收错引，不能自动判断复杂因果是否成立。
- **模型纠错反馈**：泛泛要求“检查引用”时，本机 9B 重复错误；反馈匹配的可见证据 ID 后，该次错误得到纠正。只允许一次重试，防止无界等待。
- **规则/确定性回退**：用于模型未配置或解释被拒收时保留可追踪结果；界面需明确其来源，不把回退描述为模型专家分析。
- **RAG、图谱与文献**：提供条件化知识上下文和原文定位，不自动把相似资料升级为本次观测或已审因果链。
- **“先列来源量表”自由文本提示**：0.8B 编造时间与设备台数，9B 仍出现因果和机理边界问题，故**未接入产品**。下一步应验证每条抽取事实对应的原文片段，再评价分析结论。
- **微调**：没有独立金标准和双专家签署的数据，不把本次合成及公开案例表现当作微调收益证明。
- **OCR 选型**：保留有文字层 PDF 的原生解析和页块来源；Qwen3-VL 与 PaddleOCR-VL 的图片转写仍是研究证据。正式接入前需要版面分区、页码/区域来源、未审核状态与真实中文资料复验，不能将本次试验写成已更换平台默认 OCR。
